# conversations｜對話與討論

角色提示詞、聊天生成、發言排程、引用解析與討論分析。

| 檔案／資料夾 | 負責的內容 |
| --- | --- |
| `twin_chat.py` | 個人分身私聊、歷史訊息、附件與依個人記憶生成回答。 |
| `person_chat.py` | 名人私聊、歷史訊息及依人物知識生成回答。 |
| `discussion.py` | 多人開場、辯論、總結、直接回覆與引用標記。 |
| `discussion_insights.py` | 心智圖、立場曲線、重點摘要、規則備援與快取。 |

`__init__.py` 是 Python 套件標記與簡短說明。

目前私聊模組仍保留自己的建表與訊息 SQL，個人知識庫也有專屬 SQL；本次以資料夾分類與匯入整理為主，尚未把所有 SQL 集中到 repositories。
