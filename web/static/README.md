# static｜前端畫面與素材

由 FastAPI 提供給瀏覽器；這裡的 JavaScript 在瀏覽器執行。

| 檔案／資料夾 | 負責的內容 |
| --- | --- |
| `index.html` | 主頁骨架、區塊、表單與彈出視窗。 |
| `rag-test.html` | 目前實際是 /lab 使用的媒體庫頁。 |
| `app.css` | 依序匯入 css/ 的樣式入口。 |
| `app.js` | 目前只保留 JS 已拆分的註記。 |
| `js/` | 點擊操作、請求、狀態與畫面更新。 |
| `css/` | 顏色、大小、間距、排版與響應式調整。 |
| `avatars/` | 名人頭像與四個預設使用者頭像。 |
| `images/scenes/` | 七個預設討論場景的封面。 |
| `*.png、*.jpg、*.svg` | 品牌圖示、網站圖示與登入按鈕圖片。 |
