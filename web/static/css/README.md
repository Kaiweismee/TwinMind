# static/css｜前端樣式

由 static/app.css 匯入。修改外觀先找對應畫面；共用變數位於 base.css。

| 檔案／資料夾 | 負責的內容 |
| --- | --- |
| `base.css` | 共用顏色、字型、圓角、間距與基本版面。 |
| `sidebar.css` | 側邊欄和歷史紀錄。 |
| `avatars.css` | 頭像尺寸、形狀與預設顏色。 |
| `discover.css` | 探索、人物卡片、推薦與部分個人頁面。 |
| `chat.css` | 多人聊天室、氣泡與輸入區。 |
| `twin.css` | 個人分身與名人私聊。 |
| `auth.css` | 登入和註冊。 |
| `modal.css` | 彈出視窗和遮罩。 |
| `insights.css` | 心智圖與立場分析。 |
| `responsive.css` | 小螢幕與窄視窗調整。 |
