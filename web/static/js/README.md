# static/js｜前端互動

這些是傳統 JavaScript 腳本，依 index.html 的順序載入，共用變數與函式。

| 檔案／資料夾 | 負責的內容 |
| --- | --- |
| `config.js` | 共用狀態、API 位址與預設場景。 |
| `utils.js` | API 請求、頭像、文字轉義、聊天室本機紀錄等工具。 |
| `init.js` | 事件綁定、登入檢查與頁面啟動。 |
| `profile.js` | 登入註冊、個人資料、頭像、建立分身問卷與人物介紹。 |
| `discover.js` | 探索、分類、推薦、人物選擇與主頁媒體庫。 |
| `sidebar.js` | 歷史紀錄、置頂、刪除與搜尋。 |
| `session.js` | 建立／加入討論室、參考資料與自動推進討論。 |
| `chat.js` | 多人訊息氣泡、回覆對象與來源抽屜。 |
| `twin.js` | 個人分身與名人私聊共用畫面、訊息與附件。 |
| `insights.js` | 心智圖、立場曲線、歷史預覽與詳細視窗。 |
| `notify.js` | 通知輪詢、未讀數字、提示與已讀。 |
